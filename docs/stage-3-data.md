# Подготовленные данные первого сценария

Этап 3 завершён: локальная база разбита на полные разделы, описаны калькуляторы, инженерные правила, термины и объяснения для всех намерений. Это данные для будущего сервиса, не подключённый к чату бот. Экспертная проверка и независимые контрольные вопросы остаются задачами этапа 2; классы обучения этим изменением не утверждаются.

## Состав

| Данные | Объём | Исходный файл |
| --- | ---: | --- |
| Главы и фрагменты | 8 глав, 44 раздела и 8 введений | [knowledge-sections.json](../data/definitions/knowledge-sections.json) |

| Дополнительные формулы сопротивления и преднастройки | 5 | [formula-catalog.json](../data/definitions/formula-catalog.json) |

| Эталонные первые ответы | 160 | [reference-answers.json](reference-answers.json) |

Каждый фрагмент сохраняет главу, заголовок, локальную ссылку, строки, текст целиком, SHA-256 и статусы чисел. Введения не отбрасываются: например, вся глава 07 является учебной. Таблицы остаются с оговорками своего раздела. Раздел об исторических планах редактора отмечен как контекст, а не паспортные характеристики. Требование проверить паспорт не превращается в подтверждённое паспортное число.

Правила главы 08 перенесены с сохранением всех кодов, условий и действий при невыполнении. Неизвестные доказательства не считаются выполнением условия. Исполнять инженерную проверку по ключевому слову эти записи не разрешают: оценка конкретной схемы относится к будущей реализации.

Объяснения для 46 намерений сверены с локальными разделами и связаны с соответствующими эталонами. Для диагностики, отсутствующих паспортов, цен, записи, помощи по приложению и внешних задач записаны границы. Первичные аварийные шаблоны остаются связанными с отдельным дополнением и не заменяются произвольным текстом объяснения.

## Происхождение словаря

Словарь использует термины инженерной базы и каталожную лексику, уже зафиксированную в разделе «Исходные материалы» плана. Исходный `catalogDescriptions.ts` отсутствует в доступной копии соседнего проекта; он не объявляется прочитанным или импортированным. Это явно сохранено в `terminology.catalog_origin` с исходным путём, локальным свидетельством и ограничением.

«Американка» и «футорка» отмечены как названия, требующие уточнения исполнения. Они не подтверждают посадку, резьбу или совместимость. Общий словарь различает Kv/Kvs, внутренний/наружный диаметр/DN, клапан на обратке/обратный клапан, охлаждение воды/температурный напор радиатора/гидравлический напор. Отрицания и неоднозначные слова нельзя обрабатывать слепой заменой.

Если оригинал каталога будет предоставлен позже, его нужно импортировать отдельной версией с хешем и сравнением терминов. Текущая сборка не читает соседний проект и не зависит от его наличия.

## Калькуляторы

Описаны [расход](flow-calculation-data.md), [проход, скорость и предварительный диаметр](pipe-calculation-data.md), [потери клапана по Kv и напор](pressure-calculation-data.md), а также [температурное удлинение](../data/definitions/pipe.expansion.json).

Формула температурного удлинения находится фактически в главе 06: `ΔL = α × L × Δt`, α в мм/(м·К), L в м, результат в мм. Коэффициент не подбирается по материалу. Для α в 1/К задан явный коэффициент приведения 1000. Изменение температуры — конечная температура самой трубы минус исходная; отрицательное значение означает сокращение. Это не перепад подачи и обратки и не расчёт расширительного бака.

Для SYN-088 отдельно проверяются уточнение неизвестного α и символьный множитель `10 × 50 = 500 м·К`. Множитель не является численным удлинением. Учебное α = 0,15 мм/(м·К) даёт 75 мм при 10 м и нагреве на 50 К; это вымышленный вход для арифметики, не характеристика марки. Опоры, проходки, напряжения и компенсация требуют отдельного расчёта и инструкции системы.

Дополнительный каталог описывает Re, λ = 64/Re при подтверждённом ламинарном режиме, потери Дарси — Вейсбаха при заданном применимом λ, местные потери по ζ с указанным сечением и требуемый водяной Kv по выделенному перепаду. Для каждого указаны входы, единицы, ограничения, условия обязательности, статус результата и учебная арифметика. Эти описания не означают готового расчёта полного пути, автоматического выбора режима течения, модели клапана или насоса.

## Сборка и обновление

```bash
npm run data:check
npm run data:prepare
npm run data:check-generated
npm run build
```

`data:prepare` проверяет эталоны, все определения и ссылки до записи. Итог — `data/generated/knowledge.json` со всем первым сценарием и семь отдельных файлов калькуляторов. Каталог исключён из Git; исходные определения и случаи версионируются. `data:check-generated` сравнивает каждый готовый файл с текущими входами и ничего не переписывает. Отсутствие или устаревание любого файла является ошибкой.

В общий файл включены исходная версия базы, SHA-256 всех входов после нормализации CRLF в LF, полные главы, поддерживающие источники, правила, словарь, объяснения, калькуляторы, дополнительные формулы, учебные случаи и эталоны. Время сборки и абсолютный путь рабочего каталога не записываются. Тексты исходной базы, нормативов и паспортов не обновляются из сети автоматически.

Проверяются восстановление всех восьми глав из фрагментов без потерь, точное соответствие правил таблице источника, покрытие намерений и ссылок, происхождение чисел, единицы, арифметика, состояния диалога и отказ при изменении данных. Синтетические случаи и справочные примеры не становятся независимым контрольным набором. Порядок принятия изменений описан в [ORIGIN.md](knowledge/ORIGIN.md).

Следующий этап — локальный сервис на Node.js/TypeScript, извлечение параметров и управляемый диалог на правилах. Интерфейс по-прежнему показывает демо-ответы до подключения этого сервиса.
