# Отопление частного дома: расчёт и монтаж

Создано 25.10.2026. Это база инженерных правил для реальной системы отопления
и последующего автоматического построения в редакторе. Здесь описаны физические
решения, исходные данные и проверки; программной реализации нет.

Основной случай: индивидуальный дом, закрытая водяная радиаторная система
с насосной циркуляцией. Совместная работа с тёплым полом рассмотрена на уровне
разделения температурных контуров. Расчёт петель пола, газоснабжение,
дымоудаление, электроснабжение котельной, паровое и гравитационное отопление
требуют отдельных материалов. Однотрубная схема описана как специальный случай.

Сначала определяют нагрузки и температурный режим, затем схему, приборы
и арматуру. После предварительной трассировки рассчитывают диаметры,
сопротивления и насос. Если они не согласуются, пересматривают схему, размеры
или температуры. Монтаж начинают по согласованному результату этого цикла.

## Статус чисел и правил

- **Расчётная зависимость** — формула с единицами и оговорёнными условиями.
- **Паспортное ограничение** — значение именно выбранного изделия:
  мощность, допустимое подключение, давление, зазор, радиус изгиба.
- **Проектный ориентир** — начальное предположение для подбора;
  его проверяют расчётом и по условиям объекта.
- **Учебный пример** — условные данные; они не становятся характеристиками
  товара или рекомендуемым решением для любого дома.

Планировка сама по себе не определяет мощность и диаметры. При неизвестных
ограждениях, климате или характеристиках оборудования результат остаётся
предварительным. Для монтажного решения нужны расчёт, паспорта выбранных
изделий и проверка применимых требований к конкретному объекту.

## Связь с существующей документацией

План автоматики (`skeleton-wf/docs/heating/auto-heating-plan.md`, документ исходного проекта) описывает уже сделанные шаги
редактора; план обвязки (`skeleton-wf/docs/heating/radiator-pipework-plan.md`, документ исходного проекта) — состав библиотечных
сборок; план трассировки (`skeleton-wf/docs/heating/pipe-routing-auto-plan.md`, документ исходного проекта) — геометрию труб;
подготовка каталога (`skeleton-wf/docs/heating/catalog-integration-preparation.md`, документ исходного проекта) и
присоединение к разъёмам (`skeleton-wf/docs/heating/port-attach-plan.md`, документ исходного проекта) — устройство приложения.

Их условные мощности, ограничения генераторов и значения по умолчанию
нельзя автоматически принимать за правила монтажа. Например, наличие
геометрической модели H-блока ещё не подтверждает пригодность конкретного
узла для однотрубной системы, а совпадение разъёмов не доказывает достаточный
расход. Различия перечислены в [правилах автоматизации](08-rules-for-automatic-design.md).
