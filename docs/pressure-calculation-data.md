# Данные потерь на клапане и напора

Продолжение этапа 3 после данных [расхода](flow-calculation-data.md) и [размеров трубы и скорости](pipe-calculation-data.md). Источники — полные разделы главы 05: [«Сопротивление пути»](knowledge/installation-guide/05-pipe-sizing-and-hydraulics.md#сопротивление-пути) и [«Насос»](knowledge/installation-guide/05-pipe-sizing-and-hydraulics.md#насос). Для явного водяного приближения плотности используется также [«Нагрузка и расход»](knowledge/installation-guide/05-pipe-sizing-and-hydraulics.md#нагрузка-и-расход).

## Контракты и границы

| Операция | Обязательные входы | Формула и результат |
| --- | --- | --- |
| [hydraulics.loss](../data/definitions/hydraulics.loss.json), `valve_kv_water` | Расход в м³/ч, положительный Kv в м³/ч, подтверждённая вода, подтверждение рабочей настройки и источник Kv | `Δp = (V / Kv)²`, бар; также Па и кПа. Потери на одном клапане при заданных условиях |
| [hydraulics.head](../data/definitions/hydraulics.head.json), `water_approximation` | Перепад в Па и подтверждённая вода; метод выбирается явно | `H = Δp / (1000 × 9.81)`, м; предварительная водяная оценка |
| `hydraulics.head`, `fluid_density` | Перепад в Па, среда, плотность в кг/м³, источник, рабочая температура и состав свойств | `H = Δp / (ρ × 9.81)`, м; результат при заданной плотности |

Входы — конечные числа в единицах контракта; отсутствующие значения и `null` не получают значений по умолчанию. Отрицательные расходы или перепады, неположительные Kv или плотность, неизвестные поля и строки вместо чисел недопустимы. Нулевой расход через клапан при положительном Kv даёт нулевой перепад; нулевой перепад даёт нулевой напор. Kv = 0 не разрешается даже при нулевом расходе.

Для клапана нужен Kv фактической настройки. Одного Kvs полностью открытого изделия недостаточно, пока не подтверждено такое рабочее положение; соответствие Kv рабочей настройке фиксируется явно. Источник коэффициента обязателен, но наличие текстовой ссылки само по себе не доказывает паспортную применимость. Встроенных таблиц настроек нет.

Расчёт по Kv в этом срезе поддерживает воду. Для гликоля и другой среды запрашивается применимая методика производителя; поправка по плотности автоматически не добавляется. Трубы по Дарси — Вейсбаху, местные потери по ζ, полный путь и подбор клапана пока не реализованы. Полный раздел источника сохраняется с оговорками о числе Рейнольдса, рабочем Kv и запрете повторного учёта детали по Kv, ζ и эквивалентной длине.

Для напора используется g ≈ 9,81 м/с². Водяной метод явно принимает ρ ≈ 1000 кг/м³. Если задана другая плотность, нужно выбрать `fluid_density` с её происхождением и рабочими условиями; водяной метод не игнорирует переданные свойства. Теплоёмкость для перевода перепада в напор не нужна. Плотность учебной смеси 1030 кг/м³ вымышлена для арифметики и не является характеристикой продукта.

Напор не равен высоте этажа. В замкнутой заполненной системе её не добавляют к циркуляционному напору; давление заполнения решает другую задачу. Перевод заданного перепада в метры не подтверждает выбор насоса. Для выбора нужны расход, потери наиболее требовательного полного пути с общими участками, характеристика насоса и ограничения оборудования. Потери всех параллельных веток не складываются; внутренние потери котла не учитываются дважды.

## Уточнения и условные примеры

Эталоны SYN-066 и SYN-068 содержат численный пример с допущением о воде и одновременно требуют уточнения исходных данных. В [учебных случаях потерь](../data/fixtures/hydraulics.loss.json) и [напора](../data/fixtures/hydraulics.head.json) проверяются обе части:

- Исходный структурированный запрос имеет статус `clarify` без численного результата.
- Отдельный случай `reference_view: conditional_example` имеет явно добавленные условия и точный список `reference_assumptions` из эталона. Только для него проверяется условная арифметика.

Общая проверка требует обе части и отвергает подмену допущений. Это не извлечение параметров из текста и не разрешение будущему сервису молча подставлять воду. Статус `ready` означает достаточность структурированных данных для формулы, а не профессиональное подтверждение исходных свойств или готовность инженерного решения.

При Q = 0,2 м³/ч и рабочем Kv = 0,5 на воде условный перепад равен 0,16 бар = 16 кПа = 16000 Па. При условных ρ = 1000 кг/м³ перепад 15 кПа соответствует примерно 1,529 м напора.

## Подготовка и проверка

```bash
npm run data:check
npm run data:prepare
npm run data:check-generated
```

Общая команда собирает семь файлов калькуляторов, включая `hydraulics.loss.json` и `hydraulics.head.json`, и [общий файл знаний](stage-3-data.md). Все определения проверяются до записи. Результаты воспроизводимы и исключены из Git; исходные версии, хеши, статусы чисел и оговорки сохраняются. Для операций расхода, геометрии, Kv и напора используются пять полных разделов, 100 учебных случаев и 15 связанных эталонов. Это набор разработки, не независимая оценка качества и не профессиональная проверка.

Добавлены 34 случая для потерь и напора. Проверяются Па/кПа/бар и единицы расхода, квадрат зависимости от расхода и обратный квадрат Kv, зависимость напора от плотности, нулевые и недопустимые значения, происхождение свойств, условность примеров и отказ сборки при изменении источников. Арифметика находится в [pressure-contract.mjs](../scripts/lib/pressure-contract.mjs); строки формул не исполняются как код.

Данные температурного удлинения и [весь этап 3](stage-3-data.md) также подготовлены. Подключение к чату относится к этапу 4.
