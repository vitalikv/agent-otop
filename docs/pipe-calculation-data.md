# Данные скорости потока и внутреннего диаметра

Продолжение этапа 3 после [расхода теплоносителя](flow-calculation-data.md). Источники — полные разделы главы 05: [наружный размер и проходное сечение](knowledge/installation-guide/05-pipe-sizing-and-hydraulics.md#наружный-размер-и-проходное-сечение) и [предварительный подбор по скорости](knowledge/installation-guide/05-pipe-sizing-and-hydraulics.md#предварительный-подбор-по-скорости). Сверка с локальной базой не заменяет профессиональную проверку и паспорта изделий.

## Контракты

| Операция | Входы и формула | Статус результата |
| --- | --- | --- |
| [pipe.size](../data/definitions/pipe.size.json), `outer_wall` | Наружный диаметр и стенка в мм; `dвн = dнар − 2s` | Геометрический проход круглой трубы; проход фитинга проверяется отдельно |
| [hydraulics.velocity](../data/definitions/hydraulics.velocity.json), `absolute` | Объёмный расход в л/ч и проход в мм; `v = 4 × (V / 1000 / 3600) / (π × (d / 1000)²)` | Средняя скорость в м/с при заданных условиях |
| `hydraulics.velocity`, `diameter_ratio` | Прежний и новый проходы; `(dпрежний / dновый)²` | Отношение новой скорости к прежней при явно подтверждённом неизменном положительном объёмном расходе |
| [hydraulics.diameter](../data/definitions/hydraulics.diameter.json), `by_velocity` | Расход в л/ч и выбранная скорость в м/с; `d = sqrt(4 × (V / 1000 / 3600) / (π × v)) × 1000` | Предварительный внутренний диаметр в мм; наружный типоразмер ещё не подобран |

Для скорости можно задать непосредственно `pipe_inner_mm` либо полную пару `pipe_outer_mm` и `pipe_wall_mm`. Если заданы оба представления, они должны совпадать с абсолютной погрешностью не более `0.000001 мм`. Частичная пара требует уточнения даже при известном внутреннем диаметре. Наружный размер должен быть больше двух толщин стенки; ошибочные размеры не исправляются догадкой.

Расход, размеры и скорости передаются конечными числами в единицах контракта. Значения и метод по умолчанию не выбираются. Нулевой объёмный расход даёт нулевую абсолютную скорость. Для подбора пригодного диаметра по скорости требуется положительный расход; отношение скоростей при нулевом потоке не определено. Строки, отрицательные величины и нулевые диаметры, стенки или выбранные скорости недопустимы.

В определениях заданы коэффициенты перевода м → мм, м³/ч → л/ч, л/мин → л/ч и м³/с → л/ч. Приведение пользовательского текста и единиц будет реализовано на этапе 4. Массовый расход нельзя подставлять как объёмный; для заданного объёмного расхода плотность в этих формулах не требуется.

Ориентир 0,2–0,7 м/с имеет статус `project_guideline`. Он не ограничивает численно допустимые входы формулы и не задаёт скорость автоматически. Значения вне ориентира требуют оценки условий работы. Скорость и таблица переносимой мощности не подтверждают отсутствие шума, достаточный напор, допустимый наружный размер или предельную мощность трубы.

## Подготовка и проверки

```bash
npm run data:check
npm run data:prepare
npm run data:check-generated
```

Одна команда собирает отдельные файлы в `data/generated/`: `hydraulics.flow.json`, `pipe.size.json`, `hydraulics.velocity.json`, `hydraulics.diameter.json`, а также [потери по Kv и напор](pressure-calculation-data.md). Все определения проверяются до записи файлов. Результаты исключены из Git и воспроизводятся из локальных входов; проверка готовых файлов ничего не переписывает. Файл расхода сохраняет прежний формат, а дополнительные операции получают собственные файлы.

Каждый файл содержит свой контракт, полные разделы источников с таблицами и оговорками, статусы чисел, хеши входов и снимка базы, учебные случаи и связанные эталоны. Отдельные файлы могут содержать один и тот же раздел; для расхода и геометрии используются три разных раздела главы 05. Статусы чисел зависят от раздела: водяное приближение не переносится на таблицу размеров или проектный ориентир скорости.

Добавлены 36 случаев в [pipe.size](../data/fixtures/pipe.size.json), [hydraulics.velocity](../data/fixtures/hydraulics.velocity.json) и [hydraulics.diameter](../data/fixtures/hydraulics.diameter.json). Они связаны с шестью эталонами: SYN-055, SYN-063, SYN-064, SYN-126, SYN-128 и SYN-131. Вместе с расходом это 66 учебных случаев и 13 эталонов, не независимый контрольный набор.

Проверки охватывают арифметику, обратимость формул скорости и диаметра, явные преобразования единиц, геометрические противоречия, происхождение данных и полный текст источников. Для SYN-128 и SYN-131 проверяется расчёт с переданным состоянием и уточнение без него. При исправлении 16×2 на 20×2 сохранённый расход 100 л/ч даёт скорость около 0,138 м/с вместо 0,246 м/с; отношение 0,5625 проверяется также независимо по состояниям до и после.

[geometry-contract.mjs](../scripts/lib/geometry-contract.mjs) содержит проверки структурированных входов и арифметический эталон для подготовки данных. Формулы из JSON не исполняются как код. В чате пока работает демо-провайдер; подключение операций к сервису относится к этапу 4. Срез [потерь на клапане по Kv и перевода перепада в напор](pressure-calculation-data.md) подготовлен отдельно с явными условиями применимости.
